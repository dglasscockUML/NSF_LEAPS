Lean Remarks
#

Some basic topology theorems we use over and over:

  • IsClosedMap.closure_image_eq_of_continuous shows that \(\overline{fA} = f\overline{A}\) as long as \(f: X \to Y\) is a closed map

  • IsCompact.image the continuous image of a compact set is compact

  • IsProperMap.isClosedMap shows that a proper map is closed

  • Continuous.isProperMap shows that a continuous function from a compact space to a T2 space is proper.

  • mem_closure_iff: a point \(x\) is in \(\overline{A}\) if and only if for all open \(U \ni x\), \(U \cap \overline{A} \neq \emptyset \).

  • IsClosed.isCompact: a closed subset of a compact space is compact

  • IsCompact.isClosed: in a Hausdorff space, a compact set is closed

Here’s a result we use several times that we’ll need ready access to in Lean.

Lemma 1
#

Let \(f: X \to Y\) be a continuous map of compact Hausdorff spaces. For all \(A \subseteq X\), \(\overline{fA} = f \overline{A}\).

Proof ▶

By Continuous.isProperMap, \(f\) is proper. Therefore, by IsProperMap.isClosedMap, \(f\) is closed. Therefore, by IsClosedMap.closure_image_eq_of_continuous, \(\overline{fA} = f \overline{A}\).

Lemma 3
#

Let \(X\) be a uniform space, \(x \in X\), and \(\alpha \subseteq X^2\) be an entourage. There exists an open set \(U \ni x\) such that \(\overline{U} \times \overline{U} \subseteq \alpha \).

  • exists_mem_nhds_isClosed_subset gives that since \(X\) is regular, that there is a closed neighborhood \(V\) of \(x\) contained in UniformSpace.ball x \alpha

Lemma 4 Substitute for semiopenness of a factor map
#

Let \(\pi : X \to Y\) be a surjection of compact Hausdorff spaces. For all entourages \(\alpha \subseteq X^2\), there exists a non-empty, open set \(V \subseteq Y\) such that

\[ V \times V \subseteq (\pi \otimes \pi ) \alpha . \]
Proof ▶

Let \(\alpha \subseteq X^2\) be an entourage. For all \(x \in X\), the set \(\alpha [x]\) is an open neighborhood of \(x\). By lemma 3, there exists a non-empty, open set \(U_x \subseteq X\) containing \(x\) such that \(\overline{U_x} \times \overline{U_x} \subseteq \alpha \).

By compactness, there exists a finite set \(F \subseteq X\) such that \(\cup _{x \in F} U_x = X\). Thus \(\cup _{x \in F} \overline{U_x} = X\). Since \(\pi \) is surjective, \(\cup _{x \in F} \pi \overline{U_x} = Y\). Since \(\pi \) is a closed map, the sets \(\pi \overline{U_x}\) are closed. Since \(Y\) is compact, Hausdorff, it is a Baire space, so there exists \(x \in F\) such that \(\pi \overline{U_x}\) has non-empty interior. Let \(V \subseteq Y\) be non-empty, open such that \(V \subseteq \pi \overline{U_x}\). Then

\[ V \times V \subseteq \pi \overline{U_x} \times \pi \overline{U_x} = (\pi \otimes \pi ) (\overline{U_x} \times \overline{U_x}) \subseteq (\pi \otimes \pi )\alpha , \]

as was to be shown.

Definition 10 Cancellativity relation
#

Let \(S\) be a semigroup. The cancellativity relation on \(S\) is defined by: \(s \sim _C t\) if and only if \(s = t\) or there exists \(r \in S\) such that \(rs = rt\).

Definition 11
#

Let \(S\) be a semigroup. A multiplicative semigroup relation on \(S\) is a relation \(\sim \) on \(S\) that satisfies: for all \(s, t, r \in S\), \(s \sim t\) implies \(rs \sim rt\) and \(sr \sim tr\).

Lemma 12
#

Let \(S\) be a commutative semigroup. The cancellativity relation is a multiplicative equivalence relation.

Proof ▶

  • Reflexive \(s \sim _C s\) is immediate

  • Symmetric \(s \sim _C t\) implies \(t \sim _C s\) is clear from symmetry of equals

  • Transitive \(s \sim _C t\) and \(t \sim _C k\) implies \(s \sim _C k\): \(sr = tr\) and \(tp = kp\) implies \(spr = tpr = kpr\), so \(s \sim _C k\). Note that in this argument, \(r\) or \(p\) may be the null element (or, if \(S\) has an identity, the identity)

  • Multiplicative: if \(s \sim _C t\), then \(sk \sim _C tk\): indeed, \(sr = tr\) implies \(skr = tkr\), so \(sk \sim _C tk\).

Theorem 13 Largest cancellative quotient
#

Let \(S\) be a commutative semigroup.

  1. \(S/\sim _C\) has a canonical semigroup structure.

  2. The factor map \(S \to S/\sim _C\) is a surjective semigroup homomorphism

  3. The semigroup \(S/\sim _C\) is a commutative, cancellative semigroup.

Proof ▶

1. The semigroup structure on \(S/\sim _C\) is given by \([s][t] = [st]\). This is well defined by the fact that \(\sim _C\) is multiplicative (lemma 12).

2. That the quotient map is surjective is immediate. That it is a semigroup homomorphism is immediate from the definition of the semigroup structure on \(S / \sim _C\).

3. Commutativity follows from the fact that \(S\) is commutative and that homomorphic images of commutative semigroups are commutative.

To see cancellativity, suppose \([s][r] = [t][r]\). We will show that \([s] = [t]\). Then \([sr] = [tr]\). Then \(sr \sim _C tr\), so there exists \(k \in S\) such that \(srk = trk\). Thus \(s \sim _C t\). Thus \([s] = [t]\).

Question: Do we define topological dynamical systems as semigroup actions or monoid actions? The only difference is that a monoid action requires that the identity element of the monoid acts by the identity map on the space. This is a natural assumption, but may not be required for us.

Definition 17 Semigroup action
#

Let \(S\) be a semigroup and \(X\) be a set. An action of \(S\) on \(X\) is a map \(f: S \to X \to X\) such that for all \(s, t \in S\),

\[ (f s) \circ (f t) = f (s*t). \]
Definition 18 Topological dynamical system
#

Let \(S\) be a non-empty semigroup and \(X\) be a non-empty, compact Hausdorff space. An \(S\)-system is an action of \(S\) on \(X\) such that for all \(s \in S\), \(f s\) is continuous.

Notation: for \(x \in X\), \(U \subseteq X\), \(g \in G\), and \(H \subseteq G\), we write

  1. \(gx\) to denote the image of \(x\) under \(g\);

  2. \(Gx\) to denote the set \(\{ gx \mid g \in G\} \);

  3. \(gU\) to denote the set \(\{ g x \mid x \in U\} \);

  4. \(GU\) to denote the set \(\{ gx \mid g \in G, \ x \in U\} \).

Lemma 37 Return time algebra 1
#

Suppose \(G\) is a semigroup. Let \(X\) be a \(G\)-system, \(x \in X\), \(U \subseteq X\), and \(g \in G\).

\[ g^{-1}R(x,U) = R(x,g^{-1}U). \]
Proof ▶

Each line is equivalent to the one that follows it.

  1. \(h \in R(x,g^{-1}U)\)

  2. \(hx \in g^{-1}U\)

  3. \(ghx \in U\)

  4. \(gh \in R(x,U)\)

  5. \(h \in g^{-1} R(x,U)\)

\[ R(gx,U) = R(x,U)g^{-1}. \]

Lemma 39 Return time algebra 3

Theorem 44 Every system has a minimal subsystem
#

Let \(S\) be a semigroup and \(X\) be an \(S\)-system. There exists a non-empty, closed, \(S\)-invariant subset \(Z \subseteq X\) (that is, an \(S\)-subsystem \(Z\) of \(X\)) such that the \(S\)-system \(Z\) is minimal.

Proof ▶

The subsystems of \(X\) are ordered by containment. Given any collection \(Z_i\), \(i \in I\), of \(S\)-subsystems of \(X\), \(\cap _i Z_i\) is closed, non-empty (by compactness), and \(S\)-invariant (by lemma 28). Thus, \(\cap _i Z_i\) is an \(S\)-subsystem of \(X\). This shows that every totally ordered subset of the set of subsystems of \(X\) has a lower bound in \(X\). By Zorn’s lemma, the set of subsystems has a minimal element. This minimal element is a subsystem of \(X\) that is minimal.

Theorem 45 Minimal iff dense orbits
#

Let \(S\) be a semigroup and \(X\) be an \(S\)-system. The system \(X\) is minimal if and only if for all \(x \in X\), \(\overline{Sx} = X\).

Proof ▶

By lemma 27, \(\overline{Sx}\) is an \(S\)-system. If \(X\) is minimal, then \(\overline{Sx} = X\), so \(x\) has a dense orbit.

On the other hand, if \(Z\) is a closed, non-empty, \(S\)-invariant set, then choosing \(x \in Z\), we see by the dense-orbit assumption that

\[ X = \overline{Sx} \subseteq \overline{SZ} \subseteq Z \subseteq X. \]

It follows that \(Z = X\), and hence that \(X\) is a minimal \(S\)-system.

Lemma 46 Images of minimal systems are minimal
#

Let \(S\) be a semigroup and \(\pi : X \to Y\) be a factor map of \(S\)-systems. If \(X\) is minimal, then \(Y\) is minimal.

Proof ▶

Let \(Z \subseteq Y\) be a non-empty, closed, \(S\)-invariant subset of \(Y\). Then \(\pi ^{-1} Z\) is a non-empty, closed, \(S\)-invariant subset of \(X\). By the minimality of \(X\), \(\pi ^{-1} Z = X\). Since \(\pi \) is surjective, \(Z = Y\), as desired.

Lemma 47 Minimal actions act surjectively
#

Let \(S\) be a commutative semigroup. Let \(X\) be a minimal \(S\)-system. For all \(s \in S\), the map \(s: X \to X\) is surjective.

Proof ▶

Let \(s \in S\). Since \(S\) is commutative, the set \(sX\) is a closed, \(S\)-invariant subset of \(X\). By minimality, \(sX = X\), showing that \(s\) is surjective, as desired.

0.4.5 Uniform recurrence

Definition 48 Uniformly recurrent point
#

Let \(S\) be a semigroup, \(X\) be an \(S\)-system, and \(x \in X\). The point \(x\) is \(S\)-uniformly recurrent if for all non-empty, open \(U \ni x\), the set \(R(x,U)\) is syndetic.

Lemma 49
#

Let \(S\) be a semigroup and \(X\) be a minimal \(S\)-system. For all \(x \in X\), \(x\) is \(S\)-uniformly recurrent.

Proof ▶

Let \(x \in U \subseteq X\). By theorem 45, all orbits are dense, so for \(y \in X\), there exists \(s_y \in S\) such that \(sy \in U\). Therefore, \(X = \cup _{y \in X} s_y^{-1}U\). By compactness, there exists a finite set \(F \subseteq X\) such that \(X = \cup _{y \in F} s_y^{-1} U\). By lemma 41 and lemma 37,

\[ S = R(x,X) = R(x, \bigcup _{y \in F} s_y^{-1} U ) = \bigcup _{y \in F} R(x, s_y^{-1} U) = \bigcup _{y \in F} s_y^{-1} R(x, U). \]

By definition, the set \(R(x,U)\) is syndetic.

Lemma 50
#

Let \(S\) be a semigroup and \(X\) be an \(S\)-system. If \(x \in X\) is \(S\)-uniformly recurrent, then \(\overline{Sx}\) is a minimal \(S\)-system.

Proof ▶

Note that \(\overline{Sx}\) is an \(S\)-system by lemma 27. Let \(y \in \overline{Sx}\) and \(U \subseteq \overline{Sx}\) be open and non-empty. We must show that there exists \(s \in S\) such that \(sy \in U\).

Let \(V \subseteq U\) be non-empty, open, and \(\gamma \subseteq X^2\) be an entourage such that if \((a,b) \in \gamma \) and \(a \in V\), then \(b \in U\).

Since \(V \subseteq \overline{Sx}\) is open, non-empty, there exists \(t \in S\) such that \(tx \in V\), that is, \(x \in t^{-1} V\). By assumption \(R(x,t^{-1} V)\) is syndetic: there exists a finite set \(F \subseteq S\) such that for all \(s \in S\), there exists \(f \in F\) such that \(fs \in R(x,t^{-1}U)\).

By the uniform continuity of the maps \(tf: X \to X\), \(f \in F\), there exists an entourage \(\alpha \subseteq X^2\) such that for all \(f \in F\), \(tf \alpha \subseteq \gamma \). Since \(y \in \overline{Sx}\), there exists \(s \in S\) such that \((sx,y) \in \alpha \). By syndeticity, there exists \(f \in F\) such that \(fs \in R(x,t^{-1}V)\), that is, \(tfs x \in V\).

Since \((sx,y) \in \alpha \), we have that \((tfsx,tfy) = tf(sx,y) \in tf \alpha \subseteq \gamma \). Since \(tfsx \in V\), by our choice of \(V\) and \(\gamma \), we have that \(tfy \in U\). Therefore, \(tf \in R(y,U)\), and hence \(R(y,U)\) is non-empty, as was to be shown.

Definition 53 Proximal, cf. [
#

Let \(X\) be an \(S\)-system and \(x, y \in X\). The point \(x\) is proximal to \(y\) if for all \(\alpha \) in the uniform structure on \(X\), there exists \(s \in S\) such that \((sx,sy) \in \alpha \).

Theorem 54
#

Let \(S\) be a semigroup, \(X\) be a minimal \(S\)-system, and \(x, y \in X\). If \(x\) and \(y\) are \(S\)-proximal, then \(\Delta (X)\) is contained in the \(S\)-orbit-closure of \((x,y)\).

Proof ▶

By the definition of proximal, for all entourages \(\alpha \subseteq X^2\), there exists \(s \in S\) such that \((sx,sy) \in \alpha \). By orbit closure transitivity (theorem 22), we have that \(\Delta (X)\) is contained in the \(S\)-orbit closure of \((x,y)\), as desired.

0.4.7 Regional proximality

Definition 55 Regionally proximal relation, cf. [
#

Let \(S\) be a semigroup and \(X\) be an \(S\)-system. The regionally proximal relation is defined as

\[ \RP = \bigcap _{\alpha } \overline{S \alpha }, \]

where the intersection is over all \(\alpha \) in the uniformity on \(X\), and \(S\) acts diagonally. We say that point \(x \in X\) is regionally proximal to point \(y \in X\) if \((x,y) \in \RP \).

Lemma 56
#

Let \(X\) be an \(S\)-system. The relation \(\RP \) is reflexive, symmetric, invariant, and closed.

Proof ▶

  • Symmetric: Denote by \(\Phi : X^2 \to X^2\) the map \(\Phi (x,y) = (y,x)\). Let \((x,y) \in \RP \) and \(\alpha \subseteq X^2\) be an entourage. By the definition of a uniform space, \(\Phi \alpha \) is an entourage (sometimes called \(\alpha ^{-1}\)). Since \((x,y) \in \RP \), \((x,y) \in \overline{G \Phi \alpha }\). But \(\overline{G \Phi \alpha } = \Phi \overline{G \alpha }\). Therefore, \((y,x) \in \overline{G \alpha }\), as was to be shown.

  • Invariant: The set \(G\alpha \) is clearly \(G\)-invariant. Since \(G\) acts by continuous maps,

    \[ g \overline{G\alpha } \subseteq \overline{gG \alpha } \subseteq \overline{G \alpha }, \]

    whereby \(\overline{G\alpha }\) is \(G\)-invariant. Finally, by lemma 28, an arbitrary intersection of \(G\)-invariant sets is \(G\)-invariant, so \(\RP \) is \(G\)-invariant.

  • Closed: an arbitrary intersection of closed sets is closed.

Lemma 57
#

Let \(X\) be an \(S\)-system. If \(\overline{SX} = X\), then \(\RP \) is reflexive.

Proof ▶

Let \(\alpha \subseteq X^2\) be an entourage. Since \(\overline{SX} = X\), \(\Delta \subseteq \overline{S \alpha }\). Since \(\alpha \) was arbitrary, \(\Delta \subseteq \RP \).

Lemma 60
#

Let \(S\) be a semigroup, \(X\) be an \(S\)-system, and \(x, y \in X\). For all \(A \subseteq S\),

\[ \bigcap _{\alpha } \overline{A \alpha } = \{ (x,y) \in X^2 : \Omega _A(x,y) \neq \emptyset \} . \]

In particular, setting \(A = S\), we see that \((x,y) \in \RP \) if and only if there exists \(w \in X\) and a net \((a_n, b_n, g_n)_n \subseteq X \times X \times S\) such that

\begin{align*} \lim _{n \to \infty } (a_n, b_n, g_n a_n, g_n b_n) & = (w, w, x, y). \end{align*}
Proof ▶

Let \(A \subseteq S\). Suppose \((x,y) \in \cap _{\alpha } \overline{A \alpha }\). Let \(D\) be the directed set consisting of Cartesian products of open neighborhoods of \(x\), open neighborhoods of \(y\), and entourages of \(X\). For \(n = (U,V,\alpha ) \in D\), we see from

\[ (x,y) \in \bigcap _{\alpha } \overline{A \alpha } \]

that

\[ (U \times V) \cap A \alpha \neq \emptyset . \]

Thus, there exists \((a_n,b_n) \in \alpha \) and \(s_n \in A\) such that \((s_n w_n, s_n x_n) \in U \times V\). By compactness, the net \(n \mapsto (a_n, b_n, s_n a_n, s_n b_n)\) has a cluster point. Conversely, suppose that \((x,y) \in X^2\) is such that \(\Omega _A(x,y) \neq \emptyset \): there exists \(w \in X\) and a net \((a_n, b_n, s_n)_n \subseteq X \times X \times A\) such that

\begin{align*} \lim _{n \to \infty } (a_n, b_n, s_n a_n, s_n b_n) & = (w, w, x, y). \end{align*}

Lemma 61
#

Let \(S\) be a semigroup and \(X\) be an \(S\)-system. For all \(A \subseteq S\),

\[ \Delta (\Omega _A(x,y)) = \Delta (X) \cap \bigcap _{\text{open } U \ni (x,y)} \overline{A^{-1} U}. \]
Proof ▶

Suppose \(w \in \Omega _A(x,y)\). Clearly \((w,w) \in \Delta (X)\), so we need only show that \((w,w) \in \cap _{U} \overline{A^{-1}U}\). Let \(U \subseteq X^2\) be open and contain \((x,y)\). There is a net \((a_n, b_n, s_n) \in X^2 \times A\) such that

\[ \lim _{n \to \infty } (a_n, b_n, s_n a_n, s_n b_n) = (w, w, x, y). \]

Let \(W \ni (w,w)\) be an open subset of \(X^2\). Since \(W \times U\) is an open neighborhood of \((w, w, x, y)\), there is \(n\) such that \((a_n,b_n) \in W\) and \(s_n(a_n,b_n) \in U\). Therefore,

\[ (a_n, b_n) \in s_n^{-1} U \cap W, \]

and so \(A^{-1} U \cap W \neq \emptyset \). Since \(W \ni (w,w)\) was arbitrary, we see that \((w,w) \in \overline{A^{-1}U}\), as was to be shown.

Conversely, suppose \((w,w)\) is in the right hand side. Let \(D\) be the product of the set of open neighborhoods of \((w,w)\) and the set of open neighborhoods of \((x,y)\). For \(d = (W,U)\), we get \(A^{-1} U \cap W \neq \emptyset \). Therefore, there exists \((a_d,b_d) \in W\) and \(s_d \in A\) such that \(s_d(a_d,b_d) \in U\). The net \((a_d,b_d,s_da_d, s_d,b_d)\) converges to \((w,w,x,y)\), showing that \(w \in \Omega _A(x,y)\), as desired.

Lemma 62
#

Let \(S\) be a commutative semigroup, \(X\) be a minimal \(S\)-system, and \(x, y \in X\). For all \(t \in S\),

\[ \RP = \bigcap _{\alpha } \overline{St \alpha }. \]
Proof ▶

Let \(t \in S\). Since \(St \subseteq S\), we have by the definition of \(\RP \) that

\[ \bigcap _{\alpha } \overline{S t \alpha } \subseteq \RP . \]

Conversely, suppose \((x,y) \in \RP \). Let \(\alpha \subseteq X^2\) be an entourage, and let \(W \ni (x,y)\) be open. We must show that \(W \cap St \alpha \neq \emptyset \).

Since \((x,y) \in \RP \), we have that \(W \cap S \alpha \neq \emptyset \). Thus, there exists \(s \in S\) such that \(W \cap s \alpha \neq \emptyset \). Therefore, \(s^{-1} W \cap \alpha \neq \emptyset \). Since this is an open set, by lemma 52, there exists \((a,b) \in s^{-1} W \cap \alpha \) that is \(S\)-uniformly recurrent (under the diagonal action). It follows that

\[ (a,b) \in \overline{S(a,b)}. \]

Since \((a,b)\) is \(S\)-uniformly recurrent, it follows by lemma 50 that \(\overline{S(a,b)}\) is a minimal \(S\)-system. By lemma 47 and the fact that \(S\) is commutative, we have that

\[ \overline{St(a,b)} = \overline{tS(a,b)} = t\overline{S(a,b)} = \overline{S(a,b)}. \]

Therefore, \((a,b) \in s^{-1}W \cap \alpha \cap \overline{St(a,b)}\) and so this set is non-empty. Since \(s^{-1}W \cap \alpha \) is open, \(s^{-1}W \cap \alpha \cap St(a,b) \neq \emptyset \). Lemma 63

Let \(S\) be a commutative semigroup, \(X\) be a minimal \(S\)-system, and \((x, y) \in X^2\). If \((x,y) \in \RP \), then \(\Omega _S(x,y) = X\), that is, for all \(w \in X\), there exists a net \((a_n, b_n, s_n)_n \subseteq X \times X \times S\) such that

\[ (x,y) \in \RP = \bigcap _{\alpha } \overline{St \alpha }. \]

Lemma 66

Let \(S\) be a commutative semigroup, let \(X\) be a minimal \(S\)-system, and let \(\pi : X \to Y\) be a factor map of \(S\)-systems. Then \(\RP _Y = (\pi \times \pi ) \RP _X\).

\[ S^{-1} U \cap (V \times V) \neq \emptyset . \]

Therefore,

\[ S^{-1} U \cap (\pi \otimes \pi ) \alpha \neq \emptyset . \]

Let \(S\) be a semigroup. The product of equicontinuous \(S\)-systems is an equicontinuous \(S\)-system.

Proof ▶

We need to show that the family of maps \(\{ (x,y) \mapsto (gx,gy) : g \in G\} \) from \(X \times Y\) to \(X \times Y\) is equicontinuous. Let \(\beta \subseteq (X \times Y)^2\) be an entourage. Proof ▶

  1. Let \(S\) be a semigroup, \(T\) be a semigroup with identity \(e_T\), and \(i: S \to T\) be an injective homomorphism of semigroups. Suppose that \(e_T\) is not in the range of \(i\). Theorem 162
#

Let \(S\) be a commutative semigroup. Let \(\mathcal{F}\) and \(\mathcal{G}\) be families of subsets of \(S\). Suppose that for all CRTURP sets \(B \subseteq S\) and all thick \(H \subseteq S\), if \(B \cap H \in \mathcal{F}\), then \(B \cap H \in \mathcal{G}\). Then we have

\[ \mathcal{S}\curlywedge \mathcal{F}\subseteq \mathcal{S}\curlywedge \mathcal{G}. \]
Proof ▶

  1. Let \(A \in \mathcal{S}\curlywedge \mathcal{F}\) and \(H \subseteq S\) be a thick set. Our goal is to show that \(A \cap H \in \mathcal{G}\).

  2. By theorem 16, \(\mathcal{S}\curlywedge \mathcal{F}\subseteq \mathcal{S}\), so \(A \in \mathcal{S}\).

  3. By lemma 161, there exists a thick set \(H' \subseteq H\) and a CRTURP set \(B\) such that \(A \cap H' = B \cap H'\).

  4. Since \(A \in \mathcal{S}\curlywedge \mathcal{F}\) and \(H' \in \mathcal{T}\), we have \(A \cap H' \in \mathcal{F}\) (this holds by the definition of \(\curlywedge \), even if \(\mathcal{F}= \mathcal{P}(S)\)), and so \(B \cap H' \in \mathcal{F}\).

  5. Since \(B\) is CRTURP, by our assumption, \(B \cap H' \in \mathcal{G}\).

  6. Thus \(A \cap H' \in \mathcal{G}\).

  7. Since \(H' \subseteq H\), we deduce that \(A \cap H \in \mathcal{G}\).

0.8.2 A delta set builder

Theorem 163
#

Let \(S\) be a commutative semigroup, let \(X\) be a minimal \(S\)-system, \((x, y) \in \RP \), and \(V \subseteq X\) an open neighborhood of \(y\). For all thick \(B \subseteq S\), the set \(R(x,V) \cap B \in \Delta \).

Proof ▶

Let \(B \subseteq S\) be thick. Put \(U_1 = V\) and \(B_1 = B\).

    1. By theorem 155, the set \(R(x,U_1) \cap R(V,U_1)\) is syndetic. By assumption, the set \(B_1\) is thick. By lemma 119, the intersection of a thick set and a syndetic set is non-empty. Therefore, there exists

      \[ t_1 \in R(x,U_1) \cap R(V,U_1) \cap B_1. \]

    2. Choose \(s_1 \in S\) arbitrarily. Since \(t_1 \in R(x,V) \cap B\), we see that

      \begin{align} \label{eqn_delta_it_one} s_2 \vcentcolon =s_1t_1 \in s_1 (R(x,V) \cap B). \end{align}

    3. Since \(t_1 \in R(V,V)\), \(V \cap t_1^{-1} V \neq \emptyset \). Since \(s_1\) acts surjectively (lemma 47),

      \[ U_2 \vcentcolon =s_1^{-1} V \cap s_2^{-1} V = s_1^{-1} (V \cap t_1^{-1} V) \neq \emptyset . \]

      Note that by lemma 37 and lemma 40,

      \[ R(x,U_2) = s_1^{-1} R(x,V) \cap s_2^{-1} R(x,V). \]

      Put

      \[ B_2 \vcentcolon =s_1^{-1} B \cap s_2^{-1} B. \]

    1. By theorem 155, the set \(R(x,U_2) \cap R(V,U_2)\) is syndetic. By lemma 126, the set \(B_2\) is thick. By lemma 119, the intersection of a thick set and a syndetic set is non-empty. Therefore, there exists

      \[ t_2 \in R(x,U_2) \cap R(V,U_2) \cap B_2. \]

    2. By lemma 37 and lemma 40 and the definition of \(B_2\),

      \[ t_2 \in R(x,U_2) \cap B_2 = s_1^{-1} R(x,V) \cap s_1^{-1} B \cap s_2^{-1} R(x,V) \cap s_2^{-1} B. \]

      Therefore, \(s_1 t_2, s_2 t_2 \in R(x,V) \cap B\). Therefore

      \begin{align} \label{eqn_delta_it_two} s_3 \vcentcolon =s_1s_2t_2 \in s_1 (R(x,V) \cap B) \cap s_2 (R(x,V) \cap B). \end{align}

    3. Since \(t_2 \in R(V,U_2)\), \(V \cap t_2^{-1} U_2 \neq \emptyset \). Since \(s_1s_2\) acts surjectively (lemma 47),

      \begin{align*} U_3 & \vcentcolon =(s_1s_2)^{-1} V \cap (s_1 s_3)^{-1} V \cap (s_2 s_3)^{-1} V \\ & = (s_1s_2)^{-1} \big( V \cap (s_1 t_2)^{-1} V \cap (s_2 t_2)^{-1} V \big)\\ & = (s_1s_2)^{-1} \big( V \cap t_2^{-1} U_2\big) \neq \emptyset . \end{align*}

      Note that by lemma 37 and lemma 40,

      \[ R(x,U_3) = (s_1s_2)^{-1} R(x,V) \cap (s_1s_3)^{-1} R(x,V) \cap (s_2s_3)^{-1}R(x,V). \]

      Put

      \[ B_3 \vcentcolon =(s_1s_2)^{-1} B \cap (s_1s_3)^{-1} B \cap (s_2s_3)^{-1} B. \]

    1. By theorem 155, the set \(R(x,U_3) \cap R(V,U_3)\) is syndetic. By lemma 126, the set \(B_3\) is thick. By lemma 119, the intersection of a thick set and a syndetic set is non-empty. Therefore, there exists

      \[ t_3 \in R(x,U_3) \cap R(V,U_3) \cap B_3. \]

    2. By lemma 37 and lemma 40 and the definition of \(B_3\),

      \begin{align*} t_3 & \in R(x,U_3) \cap B_3 \\ & = (s_1s_2)^{-1} (R(x,V) \cap B) \cap (s_1s_3)^{-1} (R(x,V) \cap B) \cap (s_2s_3)^{-1}(R(x,V) \cap B). \end{align*}

      Therefore, \(s_1 s_2 t_3, s_1 s_3 t_3, s_2 s_3 t_3 \in R(x,V) \cap B\). Therefore

      \begin{align} \label{eqn_delta_it_three} s_4 \vcentcolon =s_1s_2 s_3t_3 \in s_1 (R(x,V) \cap B) \cap s_2 (R(x,V) \cap B) \cap s_3 (R(x,V) \cap B). \end{align}

    3. Since \(t_3 \in R(V,U_3)\), \(V \cap t_3^{-1} U_3 \neq \emptyset \). Since \(s_1s_2s_3\) acts surjectively (lemma 47),

      \begin{align*} U_4 & \vcentcolon =(s_1s_2s_3)^{-1} V \cap (s_1 s_2 s_4)^{-1} V \cap (s_1 s_3 s_4)^{-1} V \cap (s_2s_3s_4)^{-1} V \\ & = (s_1s_2s_3)^{-1} \big( V \cap (s_1 s_2t_3)^{-1} V \cap (s_1 s_3 t_3)^{-1} V \cap (s_2s_3 t_3)^{-1}V \big)\\ & = (s_1s_2s_3)^{-1} \big( V \cap t_3^{-1} U_3\big) \neq \emptyset . \end{align*}

      Note that by lemma 37 and lemma 40,

      \[ R(x,U_4) = (s_1s_2s_3)^{-1} R(x,V) \cap (s_1s_2s_4)^{-1} R(x,V) \cap (s_1s_3s_4)^{-1}R(x,V) \cap (s_2s_3s_4)^{-1}R(x,V). \]

      Put

      \[ B_4 \vcentcolon =(s_1s_2s_3)^{-1} B \cap (s_1s_2s_4)^{-1} B \cap (s_1s_3s_4)^{-1} B \cap (s_2s_3s_4)^{-1} B. \]

Iterate ad infinitum: we get \(s_1, s_2, \dots \) such that for all \(m {\lt} n\), \(s_n \in s_m (R(x,V) \cap B)\), as was to be shown. The first instances of this are shown in ??, ??, and ??.

Theorem 164
#

Let \(G\) be a commutative, cancellative semigroup, and let \(B \subseteq G\) be CRTURP. If \(B \in \dcthickbohr \), then for all thick \(H \subseteq G\), the set \(R(x,U) \cap H \in \Delta \).

Proof ▶

Since \(B\) is a CRTURP set, there exists \(X\) be a minimal \(G\)-system, \(x \in X\), and \(U \subseteq X\) clopen so that \(B = R(x,U)\). Assume \(B \in \dcthickbohr \).

Since \(R(x,U) \in \dcthickbohr \), by lemma 117, lemma 133, and the fact that \(U\) is closed, there exists \(y \in U\) such that for all non-empty, open \(U' \ni y\), the set \(R(x,U') \in \dcthickbohr \).

Let \(\pi : X \to K\) be any equicontinuous factor of \(X\). We will show that \(\pi x = \pi y\) by showing that for all open neighborhoods \(V\) of \(\pi x\) and \(W\) of \(\pi y\), \(V \cap W \neq \emptyset \). Let \(V\) and \(W\) be open neighborhoods of \(\pi x\) and \(\pi y\) respectively. Since \(K\) is equicontinuous and \(V \ni \pi x\), \(R(\pi x, V) \in \dcsyndeticbohr \). Since \(\pi ^{-1} W \ni y\) and \(R(\pi x, V) \in \dcsyndeticbohr \), we have by lemma 131 that \(R(x,\pi ^{-1} W) \cap R(\pi x, V) \neq \emptyset \). Therefore, there exists \(g \in G\) such that \(gx \in \pi ^{-1} W\) and \(g \pi x \in V\). Thus, \(\pi g x = g \pi x \in W\) and \(g \pi x \in V\), so \(V \cap W \neq \emptyset \), as desired.

We conclude by showing that for all thick \(H \subseteq G\), the set \(R(x,U) \cap H \in \Delta \). Let \(\pi : X \to K\) be the maximal equicontinuous factor of \(X\). We showed in the previous paragraph that \(y \in U\) is such that \(\pi x = \pi y\). Therefore, \((x,y) \in \seq \). By theorem 154, \(\seq = \RP \), so \((x,y) \in \RP \). Therefore, by theorem 163, \(R(x,U) \cap H \in \Delta \).
