Some basic topology theorems we use over and over:

  • IsClosedMap.closure_image_eq_of_continuous shows that \(\overline{fA} = f\overline{A}\) as long as \(f: X \to Y\) is a closed map

  • IsCompact.image the continuous image of a compact set is compact

  • IsProperMap.isClosedMap shows that a proper map is closed

  • Continuous.isProperMap shows that a continuous function from a compact space to a T2 space is proper.

  • mem_closure_iff: a point \(x\) is in \(\overline{A}\) if and only if for all open \(U \ni x\), \(U \cap \overline{A} \neq \emptyset \).

  • IsClosed.isCompact: a closed subset of a compact space is compact

  • IsCompact.isClosed: in a Hausdorff space, a compact set is closed

  • isClosed_closure: the closure of a set is closed

0.3.1 Definitions

Let \(S\) be a set.

Definition 9 Collection
#

A collection of subsets of \(S\) is an element of \(\collections {S}\).

Definition 10 Nonempty collection
#

A collection \(\mathcal{F}\in \text{Fam}{S}\) is nonempty if \(\mathcal{F}\neq \emptyset \).

Definition 11 Proper collection
#

A collection \(\mathcal{F}\in \text{Fam}{S}\) is proper if \(\mathcal{F}\neq \powerset {S}\).

Definition 12 Upward closed collection
#

A collection of sets \(\mathcal{F}\in \collections {S}\) is upward closed if for all \(A, B \subseteq S\), ((\(A \in \mathcal{F}\) and \(A \subseteq B\)) implies \(B \in \mathcal{F}\)).

Definition 13 Family of subsets of \(S\)
#

A collection of sets \(\mathcal{F}\in \collections {S}\) is a family if it is upward closed. We denote the set of families on \(S\) by \(\text{Fam}{S}\).

Definition 14 Partition regular family
#

A family \(\mathcal{F}\in \text{Fam}{S}\) is partition regular family if for all \(A, B \subseteq S\), \(A \cup B \in \mathcal{F}\) implies \(A \in \mathcal{F}\) or \(B \in \mathcal{F}\).

Definition 15 Filter family
#

A family \(\mathcal{F}\in \text{Fam}{S}\) is a filter family if for all \(A, B \subseteq S\), \(A \in \mathcal{F}\) and \(B \in \mathcal{F}\) implies \(A \cap B \in \mathcal{F}\).

Definition 16 Ultrafilter family
#

A family \(\mathcal{F}\in \text{Fam}{S}\) is an ultrafilter family if it is both a partition regular family and a filter family.

0.3.2 Set lattice

  1. \(\cup : \text{Fam}{S}^2 \to \text{Fam}{S}\)

    1. The union of two families is a family

    2. The union of two filters is not necessarily a filter

    3. The union of two partition regular families is partition regular

  2. \(\cap : \text{Fam}{S}^2 \to \text{Fam}{S}\)

    1. The intersection of two families is a family

    2. The intersection of two filters is a filter

    3. The intersection of two partition regular families is not necessarily partition regular

  3. \((\text{Fam}{S}, \cup , \cap )\) is a sub-lattice of \((\mathcal{P}(\mathcal{P}(S)),\cup ,\cap )\)

0.3.3 Dual families

Definition 17 Dual map
#

The dual map \(*: \mathcal{P}(\mathcal{P}(S)) \to \mathcal{P}(\mathcal{P}(S))\) is defined by

\[ \mathcal{F}^* = \{ A \subseteq S : \forall B \in \mathcal{F}, \ A \cap B \neq \emptyset \} . \]

For \(\mathcal{F}\in \collections {S}\), its image \(\mathcal{F}^*\) is the dual of \(\mathcal{F}\).

Facts on the level of collections:

  1. \(*\) is antitone: for collections \(\mathcal{F}\) and \(\mathcal{G}\), if \(\mathcal{F}\subseteq \mathcal{G}\), then \(\mathcal{G}^* \subseteq \mathcal{F}^*\)

    • Proof: theorem 24

  2. For all collections \(\mathcal{F}\) and \(\mathcal{G}\), \((\mathcal{F}\cup \mathcal{G})^* = \mathcal{F}^* \cap \mathcal{G}^*\) and \((\mathcal{F}\cap \mathcal{G})^* = \mathcal{F}^* \cup \mathcal{G}^*\)

    • Proof: theorem 26 and theorem 27

Facts on the level of families:

  1. \(*\) maps families to families, that is, \(*: \text{Fam}{S} \to \text{Fam}{S}\)

    • Proof: theorem 20

    • Note that the edge cases \(\emptyset ^* = \mathcal{P}(S)\) and \(\mathcal{P}(S)^* = \emptyset \) hold by strict interpretation of the definition. Thus, in the theorems proving facts about the dual, there are no separate edge cases to consider.

    • There is a more general statement here we might favor: \(*\) takes \(\mathcal{P}(\mathcal{P}(S))\) to \(\text{Fam}{S}\).

  2. Useful equivalent formulation: for all families \(\mathcal{F}\),

    \[ \mathcal{F}^* = \{ A \subseteq S : S \setminus A \not\in \mathcal{F}\} \]

    • Proof: theorem 21

  3. \(*\) is an involution on families: for all families \(\mathcal{F}\), \((\mathcal{F}^*)^* = \mathcal{F}\)

    • Proof: theorem 22

    • There is a more general statement we might favor: \((\mathcal{F}^*)^*\) is the upward-closure of \(\mathcal{F}\).

  4. \(*: \text{Fam}{S} \to \text{Fam}{S}\) is a bijection

    • Proof: theorem 23

  5. For all families \(\mathcal{F}\), \(\mathcal{F}\) is partition regular if and only if \(\mathcal{F}^*\) is a filter

    • Proof: theorem 25

#

The family join map \(\curlyvee : \mathcal{P}(\mathcal{P}(S))^2 \to \mathcal{P}(\mathcal{P}(S))\) is defined by

Theorem 25
#

\(\mathcal{F}\) is a partition regular family if and only if \(\mathcal{F}^*\) is a filter

Proof ▶

By theorem 20 and theorem 22, \(\mathcal{F}\) is family if and only if \(\mathcal{F}^*\) is a family. Then, in the following list, each statement is equivalent to the one that follows it.

  1. \(\mathcal{F}\) is a partition regular family

    • definition

  2. for all \(A, B \subseteq S\), if \(A \cup B \in \mathcal{F}\), then \(A \in \mathcal{F}\) or \(B \in \mathcal{F}\)

    • theorem 22

  3. for all \(A, B \subseteq S\), if \(A \cup B \in (\mathcal{F}^*)^*\), then \(A \in (\mathcal{F}^*)^*\) or \(B \in (\mathcal{F}^*)^*\)

    • theorem 21

  4. for all \(A, B \subseteq S\), if \(S \setminus (A \cup B) \not\in \mathcal{F}^*\), then \(S \setminus A \not\in \mathcal{F}^*\) or \(S \setminus B \not\in \mathcal{F}^*\)

    • set theory: for \(X, Y \subseteq Z\), \(Z \setminus (X \cup Y) = (Z \setminus X) \cap (Z \setminus Y)\)

  5. for all \(A, B \subseteq S\), if \((S \setminus A) \cap (S \setminus B) \not\in \mathcal{F}^*\), then \(S \setminus A \not\in \mathcal{F}^*\) or \(S \setminus B \not\in \mathcal{F}^*\)

Theorem 28
#

If \(\mathcal{F}\) and \(\mathcal{G}\) are families, then \(\mathcal{F}\curlyvee \mathcal{G}\) is a family.

Proof ▶

By definition, \(\mathcal{F}\curlyvee \mathcal{G}\) is a collection of subsets of \(S\). We need to show that it is upward closed.

If \(\mathcal{F}= \emptyset \) or \(\mathcal{G}= \emptyset \), then \(\mathcal{F}\curlyvee \mathcal{G}\) is a family, and hence is upward closed. Assume \(\mathcal{F}\neq \emptyset \) and \(\mathcal{G}\neq \emptyset \). We will show that \(\mathcal{F}\curlyvee \mathcal{G}\) is upward closed.

Let \(A \in \mathcal{F}\curlyvee \mathcal{G}\) and \(A \subseteq A' \subseteq S\). We must show that \(A' \in \mathcal{F}\curlyvee \mathcal{G}\). By definition, there exists \(B \in \mathcal{F}\) and \(C \in \mathcal{G}\) such that \(A = B \cap C\). Define \(B' = B \cup A'\) and \(C' = C \cup A'\).

We claim that

  1. \(B' \in \mathcal{F}\),

  2. \(C' \in \mathcal{G}\),

  3. \(B' \cap C' = A'\).

If we show all three, then we are done, since it will follow that \(A' \in \mathcal{F}\curlyvee \mathcal{G}\).

(1) Since \(B \in \mathcal{F}\), \(\mathcal{F}\) is upward closed, and \(B \subseteq B' \subseteq S\), we have that \(B' \in \mathcal{F}\).

(2) Since \(C \in \mathcal{G}\), \(\mathcal{G}\) is upward closed, and \(C \subseteq C' \subseteq S\), we have that \(C' \in \mathcal{G}\).

(3) From set theory, union distributes over intersection (\(X \cup (Y \cap Z) = (X \cup Y) \cap (X \cup Z)\)). We see

\[ B' \cap C' = (B \cup A') \cap (C \cup A') = (B \cap C) \cup A' = A \cup A'. \]

Since \(A \subseteq A'\), \(A \cup A' = A'\), as desired.

Theorem 31 \(\curlyvee \) is associative

\[ (\mathcal{F}\curlyvee \mathcal{G}) \curlyvee \mathcal{H}= \mathcal{F}\curlyvee (\mathcal{G}\curlyvee \mathcal{H}). \]

The topological dynamical systems in Mathlib are called Flows. See https://leanprover-community.github.io/mathlib4_docs/Mathlib/Dynamics/Flow.html. A flow is an action of a topological monoid on a topological space by continuous maps. Question: Do we define topological dynamical systems as semigroup actions or monoid actions? The only difference is that a monoid action requires that the identity element of the monoid acts by the identity map on the space. This is a natural assumption, but may not be required for us.

Answer: semigroup actions. It seems we can do everything we need to do while avoiding monoids, and especially monoid actions.

Question: Do we define topological dynamical systems with phase space “compact Hausdorff” or “uniform”? Uniform is more general, but perhaps is not necessary for our purposes.

\[ X = \bigcup _{x \in X} \gamma [x]. \]

\[ X = \bigcup _{z \in Z} \gamma [z]. \]
