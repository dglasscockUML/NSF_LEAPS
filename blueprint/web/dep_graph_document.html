Definition 9Cancellative

A semigroup \(S\) is cancellative if it is both left cancellative and right cancellative. That is, if for all \(s, t, r \in S\), \(rs = rt\) or \(sr = tr\) implies \(s = t\). Equivalently: if for all \(r \in S\), left multiplication by \(r\) and right multiplication by \(r\) as maps from \(S \to S\) are both injective.
